Anatomy of an ISO 4406 code

ISO 4406 expresses fluid cleanliness as three scale numbers separated by slashes, for example 18/16/13. Each number represents the count of particles per millilitre at or above a given size, measured with an automatic particle counter calibrated to ISO 11171:

Reading the code 18/16/13
PositionParticle sizeScale numberParticles per mL
First≥4 µm(c)18>1,300 to 2,500
Second≥6 µm(c)16>320 to 640
Third≥14 µm(c)13>40 to 80

The counts are cumulative: the ≥4 µm(c) figure includes every particle at 6 and 14 µm(c) too. That's why the first number is always the largest.

When particles are counted by microscope rather than an APC, ISO 4406 uses a two-part code for ≥5 µm and ≥15 µm, written with a dash in the first position, for example -/16/13.

What one step on the scale means

Each step up the scale roughly doubles the particle concentration. Going from 16/14/11 to 18/16/13 isn't "a bit dirtier": it's about four times as many particles at every size.

That's why cleanliness targets are worth taking seriously, and why a calibration drift that shifts sizing slightly can move a code by a full step without any change in the fluid.

Reporting rules worth knowing

  • Low counts are flagged. When fewer than 20 particles were actually counted at a size, the scale number for that size is marked with "≥" to show reduced statistical confidence, for example 14/12/≥7.
  • The code is a summary. Two fluids with the same code can have different size distributions within each range. For trending and troubleshooting, ask for the raw counts.
  • Method matters. A code is only comparable with another if both counters are calibrated to ISO 11171 and samples were handled the same way.

Because the size bases and counting methods differ, there's no exact conversion between systems. Published cross-reference charts are approximations. If you're moving a specification from NAS 1638 to ISO 4406 or AS4059, set the new limits from measured data rather than a lookup table.

When to question a cleanliness code

  • The code jumped by two or more steps with no change to the system or filtration.
  • Repeat tests of the same bottle differ by more than a step.
  • Two labs report different codes for the same fluid.
  • The counter's last ISO 11171 calibration is overdue or undocumented.
  • The sample was hazy, wet or dark, any of which can distort light-extinction counting.
